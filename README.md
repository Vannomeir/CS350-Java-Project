# EXPENSE TRACKER
The Expense Tracker is a Java-based application designed to help users manage and monitor their personal finances. The system allows users to record their income and expenses, categorize their spending, and keep track of their overall financial activity. 
The application records the user's total income, total expenses and calculates the remaining balance, making it easier to determine whether they are saving money or overspending. By keeping a record of transactions, users can also review their spending habits and gain a better understanding of where their money is going. 
This project was developed as a practical Java programming project to demonstrate concepts such as user input, variables, conditional statements, loops, methods, data storageand basic financial calculations.

# MAIN FEATURES
- Record income and expenses
- Categorize expenses
- Calculate total income and expenses
- Display the remaining balalnce
- Identify whether the user is within this budget or overspending
- Review recorded transactions
- Simple and user-friendly menu-based interface

# Technologies used
- Java
- Java collections/Data Structures

# Project Goal
The main goal of this project is to provide a simple tool for managing personal finances while demonstrating the practical application of Java programming concepts.
